## Convenções

- Um ADR aceito não é reescrito para esconder decisões anteriores.
- Mudanças incompatíveis exigem um novo ADR.
- Valores derivados precisam indicar sua fonte e confiabilidade.
- Decisões de segurança registram explicitamente isolamento de tenant e usuário.
